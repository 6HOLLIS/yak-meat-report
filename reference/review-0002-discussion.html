思考题一：出栏率为何只有 15%

Q1. 牦牛出栏率只有 15%，远低于普通肉牛。除草场周期外还有哪些因素拖后腿？

学生回答

不知道想不出来。

评分：0/10 — 放弃作答。课程此处展开不足，责任在教师

补课：15% 出栏率 = 三重锁

层面因素详细机制
文化宗教 惜杀惜售 藏传佛教不杀生观念；牦牛头数 = 家庭财富象征（类似储蓄账户），不是出肉工具。不到急需用钱不卖，即使冬天掉膘也比卖了强
经济理性 活牛 = 抗风险池 藏区缺乏银行和保险体系，多养几头牛就是对抗突发风险的唯一手段。卖牛的短期收益 vs 留着牛的长期安全感，后者往往胜出
基础设施 牧道不通、屠宰场太远 牧民在海拔 4000+ 米的分散牧场，牛贩子一年来一两次。想卖也运不出去——通路成本高于牛本身的价值

一句话记忆

15% 不是技术问题，是「不想卖 + 不敢卖 + 卖不出去」三重锁死。要破局，合作社组织化比技术改良更关键。

思考题二：产业链延伸方向

Q2. 你是合作社负责人，业务从养殖端往哪个方向延伸？为什么？

学生回答

没懂你的问题。在养殖端延伸就是第一个环节，育肥牛最赚钱，就尽力全部弄成育肥牛。

评分：3/10 — 审题偏差；思维局限在养殖端内部，没看见下游更大的利润池

问题分析
审题错误 问的是「从养殖端往产业链前后端延伸」，不是「在养殖端内部怎么选」
正确方向 往下游延伸：养殖 → 屠宰 → 分割包装 → 品牌零售。每往下走一步，利润多吃一截。育肥牛赚 2,861 元/头，但如果自己屠宰 + 分割 + 包装 + 贴品牌，能多吃数倍
参考答案 梅陇合作社模式：入股整合 → 统一养殖 → 统一屠宰 → 统一品牌 → 牧民按股分红。农小蜂报告里 0002 课程引用了这个案例

一句话记忆

养殖合作社的出路不是把牛养得更好，是从「养牛」变成「卖肉」。利润在下游，不在养殖端。

思考题三：鲜肉冻肉比例预测

Q3. 五年后鲜肉冻肉比例会从 20:80 变成多少？为什么？

学生回答

鲜肉占比会提升很多，但大概率不会超过冻肉。
提升原因：冷链运输技术的成熟和完善、牦牛肉知识的用户普及、养殖层面的努力。
不超冻肉原因：成本限制导致售价上升；牦牛肉市场本就不大，要求新鲜的用户很少，需求量受限。

评分：8/10 — 方向正确，逻辑自洽。缺具体数字、缺供给端视角、零和市场假设需修正

维度你的回答评价与补充
方向判断 鲜肉↑ 但不超冻肉 ✅ 合理。冻肉在可预见的未来仍是主力，因为草场周期不可消除
上涨驱动力 冷链 + 认知 + 养殖改善 ✅ 三个全中。漏了一个：错峰出栏技术——通过补饲把屠宰季拉长，这是鲜肉供给的底层条件
不超冻肉的理由 成本 → 价格 → 市场小 → 需求量受限 ⚠️ 推理链成立，但有个隐含假设需要警惕：你默认市场是零和的——那只在需求不变时成立。实际上牛肉消费在增长(+5.4%)，进口在被限制，蛋糕本身在膨胀
最大缺陷 没有给具体数字 ❌ 商业分析最终要落到判断。「很多」「大概率」是逃避。猜一个数比不说要好——例如「我认为会到 35:65」

Q3 优秀之处

这道题说明你已经有商业分析的感觉了：从需求端、成本端、供给端分别推演，形成了自洽的推理链。下一步要练的就是把这个感觉用数字表达出来——哪怕猜错，猜的过程本身就是技能训练。

本节核心框架回顾

供应链速记

  1. 养殖端：牧户 → 合作社/规模场；传统出栏 5-8 年，现代 2-3 年；出栏率仅 15%
  2. 流通端：牛贩子主导，牧户议价弱，「企业+合作社+牧户」模式落地率低
  3. 加工端：初级加工（简单分割）62%；精深加工 38%（目标 43%）；屠宰旺季集中 9-11 月
  4. 销售端：藏区自消费 >80%；电商 31%（暴增中）；鲜肉:冻肉 = 20:80
  5. 利润池：育肥牛 2,861 元/头（养殖端最高）；精深加工 + 品牌零售——利润在后端

六个核心痛点

  1. 出栏率极低 (15%) —— 文化 + 经济 + 基建三重锁
  2. 防疫体系薄弱 —— 80% 兽医中专以下
  3. 加工水平低 —— 产品结构单一，副产物浪费
  4. 交通成本高 —— 远离消费市场，运费曾占成本一半
  5. 品牌建设滞后 —— 好东西按普通牛肉卖
  6. 季节性供需矛盾 —— 全年 80% 卖冻肉，消费者却偏好鲜肉
